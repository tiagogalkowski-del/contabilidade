# Contabilidade — Sistema Contábil FURB

Sistema contábil acadêmico desenvolvido em React + Vite, seguindo as 10 etapas da atividade da FURB.

## Etapa 1 — Estrutura
- Sete menus
- Exercício fixo de 01/01/2026 a 31/12/2026
- Navegação entre menus
- Base preparada para as próximas etapas

## Rodar localmente
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
